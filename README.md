# Gorge Remotion Arabic

Reference bundle assembled from the user's public repos for professional Remotion-based
Arabic video work: word-level captions, RTL text rules, markup, layout and Lemo-Opuscar
visual styles.

These are references; the free GorgeReels cloud renderer still uses FFmpeg/libass to stay
within the 512 MiB Render free tier. Use these docs when moving rendering to a bigger
machine or a client-side Remotion project.

Sources: [VideoReels](https://github.com/manmdom/VideoReels) and [Lemo](https://github.com/manmdom/Lemo).
